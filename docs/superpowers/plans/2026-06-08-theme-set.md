# Theme Set Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a curated set of account-synced, selectable UI themes built on a single-source token template, so future tokens/themes/components flow in with no per-theme work.

**Architecture:** Refactor the Tailwind v4 `@theme inline` block from literal values to a stable name→`var()` mapping; hold default (current dark) token values in `:root` and per-theme deltas in `[data-theme="…"]` blocks in a new `themes.css`. A small cookie-driven provider sets `data-theme` on `<html>` server-side (zero flash) and persists the choice to `user_profiles.theme` + a cookie. A settings selector renders from a `lib/themes.ts` registry. The exact light/extra palettes are produced via Claude Design and only fill token values.

**Tech Stack:** Next.js 16 (App Router, `app/[locale]`), Tailwind CSS v4 (`@theme inline`), Better Auth, Drizzle schema + raw `psql` migrations, custom tsx test runner (`tests/unit/*.test.ts`).

Source: `docs/superpowers/specs/2026-06-08-theme-set-design.md`. Read it before starting.

## File structure (decomposition)

- **`app/[locale]/themes.css`** (new) — `:root` = all tokens at default (current dark) values; one `[data-theme="<id>"]` block per non-default theme (deltas only). Single place to add/edit a theme's palette.
- **`app/[locale]/globals.css`** (modify) — `@theme inline` becomes a name→`var()` mapping; imports `themes.css`; `color-scheme` becomes token-driven.
- **`lib/themes.ts`** (new) — theme registry (`THEMES`, `DEFAULT_THEME`, `ThemeId`, `isThemeId`). Single source for selector + API validation + type.
- **`components/theme-provider.tsx`** (new) — client context: `theme` + `setTheme` (optimistic DOM + cookie + PATCH).
- **`components/providers.tsx`** (modify) — wrap `ThemeProvider`.
- **`app/[locale]/layout.tsx`** (modify) — resolve initial theme (cookie → DB if authed → default) and set `<html data-theme>`.
- **`app/api/profile/route.ts`** (modify) — `PATCH` accepts + validates `theme`.
- **`src/db/schema.ts`** (modify) + **`drizzle/0018_user_theme.sql`** (new) — `theme` column.
- **`lib/auth/better-auth.ts`** (modify) — seed `theme='dark'` in the signup-hook insert.
- **`app/[locale]/settings/page.tsx`** (modify) — "Appearance / מראה" selector section.
- **`components/persistent-timer-bar.tsx`**, **`components/landing/hero.tsx`** (modify) — replace hardcoded colors with tokens.
- **`tests/unit/themes.test.ts`** (new) — registry/guard unit tests.
- **`messages/he.json`, `messages/en.json`** (modify) — Appearance section + theme labels.

> Ordering rationale: Task 1 is a **value-preserving refactor** (still 100% dark) so the app never visually regresses; later tasks add the switching machinery; the real palettes (Task 9, Claude Design) plug in last.

 *  block in app/[locale]/themes.css + one entry here. Components never import this

export interface ThemeMeta {
  id: string;
  labelHe: string;
  labelEn: string;
  base: "dark" | "light";

  swatch: [string, string, string];

export const THEMES: ThemeMeta[] = [
  { id: "dark", labelHe: "כהה", labelEn: "Dark", base: "dark", swatch: ["#0a0a0a", "#1a1a1a", "#faff69"] },

export const DEFAULT_THEME = "dark";

export type ThemeId = (typeof THEMES)[number]["id"];

export function isThemeId(value: unknown): value is ThemeId {

### Task 5: Theme provider + SSR `data-theme`

- [ ] **Step 1: Create `components/theme-provider.tsx`:**

```tsx
"use client";

import { createContext, useContext, useState, useCallback, type ReactNode } from "react";
import { DEFAULT_THEME, isThemeId } from "@/lib/themes";

interface ThemeContextValue {
  theme: string;
  setTheme: (id: string) => void;
}

const ThemeContext = createContext<ThemeContextValue>({
  theme: DEFAULT_THEME,
  setTheme: () => {},
});

const COOKIE = "theme";

function writeCookie(id: string) {
  // 1 year, root path, Lax. Not httpOnly on purpose — the client owns switching.
  document.cookie = `${COOKIE}=${id}; path=/; max-age=31536000; samesite=lax`;
}

export function ThemeProvider({ initialTheme, children }: { initialTheme: string; children: ReactNode }) {
  const [theme, setThemeState] = useState(isThemeId(initialTheme) ? initialTheme : DEFAULT_THEME);

  const setTheme = useCallback((id: string) => {
    if (!isThemeId(id)) return;
    const prev = theme;
    setThemeState(id);
    document.documentElement.dataset.theme = id; // optimistic, no flash
    writeCookie(id);
    fetch("/api/profile", {
      method: "PATCH",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ theme: id }),
    }).catch(() => {
      // rollback on failure
      setThemeState(prev);
      document.documentElement.dataset.theme = prev;
      writeCookie(prev);
    });
  }, [theme]);

  return <ThemeContext.Provider value={{ theme, setTheme }}>{children}</ThemeContext.Provider>;
}

export function useTheme() {
  return useContext(ThemeContext);
}
```
