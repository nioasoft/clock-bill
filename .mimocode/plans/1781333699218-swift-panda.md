# Clock-Bill / Monit — Improvement Plan (Revised)

## Audit corrections applied

The original audit had 5 false positives that were verified safe and removed:
- Projects DELETE FK — schema cascades correctly (`onDelete: "cascade"` on `time_entries.projectId`)
- Timer-rate "vulnerability" — Zod enforces `min(0)` server-side
- Dynamic import "smell" — standard Next.js code splitting
- Throw-for-control-flow — valid pattern within same codebase
- `lib/error-logging.ts` — used by `error-boundary.tsx` and `global-error.tsx`, not dead code

## Phase 2: API Route Deduplication & Consistency

### 2a. Extract row-to-response mappers

**New files:**
- `lib/transformers/entries.ts` — `rowToEntryResponse(row)` (used 4x across entries routes)
- `lib/transformers/projects.ts` — `rowToProjectResponse(row)` (used 2x)
- `lib/transformers/clients.ts` — `rowToClientResponse(row)` (used 2x)

### 2b. Extract shared SQL column lists

**New file:** `lib/sql-columns.ts`

Define `ENTRY_SELECT_COLUMNS`, `PROJECT_SELECT_COLUMNS`, `CLIENT_SELECT_COLUMNS` constants.

### 2c. Create `withAuth` wrapper

**New file:** `lib/api-helpers.ts`

```ts
export function withAuth(handler: (user: User, request: NextRequest) => Promise<NextResponse>) {
  return async (request: NextRequest) => {
    const user = await getUser();
    if (!user) return NextResponse.json({ success: false, error_code: "UNAUTHORIZED", message: "לא מחובר" }, { status: 401 });
    return handler(user, request);
  };
}
```

### 2d. Standardize logging

Replace `console.error()` in API routes with `createLogger("module").error()`. Affected: `clients/route.ts`, `entries/route.ts`, `projects/route.ts` and their `[id]` variants.

### 2e. Fix inconsistent response shape

**File:** `app/api/charge-documents/route.ts`

Change `{ success, data: rows }` to `{ success, chargeDocuments: rows }`. Update frontend callers.

### 2f. Optimize projects POST (2 round-trips → 1)

**File:** `app/api/projects/route.ts`

Replace INSERT + re-SELECT with a CTE:
```sql
WITH ins AS (
  INSERT INTO projects (...) VALUES (...) RETURNING *
)
SELECT ins.*, c.name as client_name FROM ins JOIN clients c ON ins.client_id = c.id
```

### 2g. Move cross-field validation into Zod schemas

**File:** `app/api/projects/route.ts`

Move `fixedMonthlyEnabled + fixedMonthlyFee` and date range checks into `createProjectSchema` via `.refine()`.

## Phase 3: Performance

**File:** `app/api/clients/route.ts`

Add `?limit=&offset=` params. Default limit: 100. Return `{ clients, pagination: { total, limit, offset, hasMore } }`.

### 3b. Optimize clients GET aggregation

**File:** `app/api/clients/route.ts`

Cache `total_billed` and `total_hours` on the `clients` table, update when entries change. The current `SUM()` across all time_entries runs on every page load.

### 3c. Optimize admin stats queries

**File:** `app/api/admin/stats/route.ts`

Merge 9 parallel `adminQuery` calls (through a 2-connection pool) into fewer queries using CTEs.

### 3d. Adopt TanStack Query (separate PR)
