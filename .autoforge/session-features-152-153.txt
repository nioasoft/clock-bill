**Feature #153: Project Budget Progress**

Implemented visual progress bar for project budgets:

1. **New API Endpoint (app/api/projects/[id]/stats/route.ts):**
   - GET /api/projects/[id]/stats returns project statistics
   - Calculates total hours from sum of time entry durations
   - Returns entry count for the project
   - Verifies user ownership before returning data

2. **UI Implementation (app/projects/[id]/page.tsx):**
   - Added projectStats state to store fetched statistics
   - Added useEffect to fetch stats when project loads
   - Created getBudgetProgress() function that calculates progress based on pricing model:
     * package/mixed: Shows hours used vs packageHours included
     * retainer: Shows hours used vs retainerHours included
     * fixed: Shows actual cost (hours × hourlyRate) vs fixedBudget
     * hourly: No progress bar (no budget to track)
   - Created renderProgressBar() function for visual display
   - Color-coded progress:
     * Green: < 80% of budget used
     * Yellow: ≥ 80% of budget used
     * Red: Over budget (with warning text)
   - Progress bar displays percentage, current/total values
   - Updated project totals card to use fetched stats

### Progress Calculation Examples

**Package/Mixed/Retainer Models:**
percentage = (totalHours / packageHours) × 100
Example: 15 hours used / 20 hour package = 75%

**Fixed Budget Model:**
actualCost = totalHours × hourlyRate
percentage = (actualCost / fixedBudget) × 100
Example: $800 / $1000 budget = 80%
