**Implementation Components**:

1. **Core Notification Library** (`lib/notifications.ts`):
   - `checkNotificationPermission()` - Checks browser support and permission
   - `requestNotificationPermission()` - Requests permission from user
   - `showNotification(title, body, icon?)` - Creates browser notification
   - `showLongTimerNotification(minutes)` - Long timer warning
   - `showDailyReminderNotification(todayHours)` - Daily reminder
   - Helper functions for reminder timing

2. **React Hook** (`hooks/use-notifications.ts`):
   - Permission state management
   - Settings loading from database
   - Methods for triggering notifications
   - Long timer and daily reminder logic

3. **Settings UI** (`app/settings/page.tsx`):
   - Permission status display (granted/denied/default/not supported)
   - Visual indicators (green/yellow/red dots)
   - "אפשר התראות" (Enable Notifications) button
   - "נסה התראה" (Test Notification) button
   - Long timer settings (enable/disable, threshold)
   - Daily reminder settings (enable/disable, time)
   - Save settings button

4. **Database Schema** (`src/db/schema.ts`):
   - `longTimerEnabled` BOOLEAN - Default: true
   - `longTimerThreshold` INTEGER - Default: 120 minutes
   - `dailyReminderEnabled` BOOLEAN - Default: false
   - `dailyReminderTime` TEXT - Default: "09:00"
   - `lastReminderDate` DATE - Tracks last reminder

5. **API Endpoints**:
   - GET /api/profile - Loads notification settings
   - PATCH /api/profile - Updates notification settings
   - POST /api/profile/reminder-shown - Updates last reminder date
