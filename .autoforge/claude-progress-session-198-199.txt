### Features #198 & #199: Date/Time Format Preferences

**Complete implementation of user-selectable date and time formatting:**

1. **Database Schema Updates** (src/db/schema.ts):
   - Added `dateFormat` column to user_profiles table
   - Added `timeFormat` column to user_profiles table
   - Default values: dateFormat = 'DD/MM/YYYY', timeFormat = '24h'
   - Types: TEXT columns with NOT NULL constraint

2. **Database Migration** (lib/db.ts):
   - Added migration to create date_format column if not exists
   - Added migration to create time_format column if not exists
   - Uses ALTER TABLE ADD COLUMN IF NOT EXISTS for safety
   - Default values applied to existing profiles

3. **API Updates** (app/api/profile/route.ts):
   - Updated Profile interface to include dateFormat and timeFormat
   - Updated ProfileUpdateRequest interface to accept new fields
   - GET handler returns dateFormat and timeFormat in profile data
   - PATCH handler accepts and saves dateFormat and timeFormat
   - Added to SELECT query with proper aliasing
   - Added to UPDATE query with parameter binding

4. **Settings UI** (app/settings/page.tsx):
   - Added state variables: dateFormat, timeFormat
   - Initialized from profile data on fetch
   - Added date format dropdown with 3 options:
     * DD/MM/YYYY (יום/חודש/שנה) - default
     * MM/DD/YYYY (חודש/יום/שנה)
     * YYYY-MM-DD (שנה-חודש-יום)
   - Added time format dropdown with 2 options:
     * 24h (24 שעות) - displays 14:30
     * 12h (12 שעות) - displays 02:30 PM
   - Both fields include helpful Hebrew descriptions
   - Integrated with existing profile save functionality

5. **Formatting Utilities** (lib/format.ts):
   - Server-side formatting functions for date and time
   - formatDate(): Formats dates according to preference
   - formatTime(): Formats times in 12h or 24h format
   - formatDateTime(): Combines date and time formatting
   - formatDateRange(): Formats date ranges
   - formatDuration(): Formats duration in Hebrew (שע׳/דק׳)
   - getUserFormatPreferences(): Fetches user preferences from API
   - Full TypeScript type safety
   - Supports Hebrew locale (he-IL)

6. **Client-Side Formatting** (lib/client-format.ts):
   - Client-compatible versions of all formatting functions
   - Same API as server-side utilities
   - Works directly in React components

7. **React Hook** (hooks/use-format-preferences.ts):
   - useFormatPreferences() hook for client components
   - Fetches user's format preferences from API
   - Returns dateFormat, timeFormat, and loading state
   - Handles errors gracefully with defaults
