**Feature #58: Pause Timer**
Implemented from scratch with full pause/resume functionality:

### Database Changes (lib/db.ts)
- Added `paused_at TIMESTAMP` column to track when timer was paused
- Added `total_paused_time INTEGER DEFAULT 0` to accumulate paused milliseconds
- Migration code included for existing databases

### API Endpoints Created
1. **POST /api/timer/pause/route.ts**
   - Sets paused_at to current timestamp
   - Returns 400 if already paused or no running timer
   - Validates user authentication and ownership

2. **POST /api/timer/resume/route.ts**
   - Calculates current pause duration (now - paused_at)
   - Adds to total_paused_time accumulator
   - Clears paused_at to NULL
   - Returns 404 if no paused timer found

3. **Updated GET /api/timer/running/route.ts**
   - Selects paused_at and total_paused_time fields
   - Subtracts total_paused_time from elapsed calculation
   - If currently paused, subtracts current pause duration
   - Returns pausedAt field to UI

4. **Updated POST /api/timer/stop/route.ts**
   - Reads total_paused_time and paused_at from database
   - Subtracts both paused durations from final calculation
   - Clears paused_at when stopping

### UI Changes (app/dashboard/page.tsx)
- Added pausingTimer and resumingTimer state variables
- Added handlePauseTimer and handleResumeTimer functions
- Updated timer widget to show pause/resume buttons:
  - When active: Yellow "השהה טיימר" button
  - When paused: Green "חדש טיימר" button + status text "טיימר מושהה"
  - Always show Red "עצור טיימר" button
- Both pause and resume refresh running timer state after completion
- Loading states show during pause/resume operations
