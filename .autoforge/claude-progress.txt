### Features #187 & #188: Keyboard Shortcuts Implementation

**Complete keyboard shortcut system for power users:**

1. **Custom Hook (`hooks/use-keyboard-shortcut.ts`):**
   - Reusable React hook for handling keyboard shortcuts
   - Supports simple keys and modifier combinations (Ctrl, Alt, Shift, Meta)
   - Prevents repeated firing with `event.repeat` check
   - Prevents default behavior when requested
   - Proper cleanup of event listeners
   - Uses refs to avoid stale closures
   - Can be disabled when needed
   - Examples:
     * Simple key: `useKeyboardShortcut({ key: "t", callback })`
     * With modifiers: `useKeyboardShortcut({ key: "k", ctrlKey: true, callback })`
     * Escape to close: `useKeyboardShortcut({ key: "Escape", callback })`

2. **Feature #187: Timer Keyboard Shortcut:**
   - Press 't' key on dashboard to toggle timer
   - Behavior based on current timer state:
     * No timer running: Opens "Start Timer" modal
     * Timer running: Pauses the timer
     * Timer paused: Resumes the timer
   - Visual hint: Shows "T" in a kbd element next to "טיימר מהיר" heading
   - Hidden on mobile, visible on desktop (sm:inline-block)
   - Styled with border and monospace font
   - Integrated with existing timer controls

3. **Feature #188: Quick Entry Shortcut:**
   - Press 'n' key on entries page to toggle quick entry form
   - Opens form if closed, closes if open
   - Press 'Escape' to cancel and close form
   - Auto-focuses project select dropdown when opening
   - Visual hint: Shows "N" in a kbd element next to the "+ רשום זמן" button
   - Hidden on mobile, visible on desktop
   - Works with existing form state and validation

4. **Dashboard Changes (`app/dashboard/page.tsx`):**
   - Added `useKeyboardShortcut` import
   - Created `handleTimerShortcut()` function
   - Calls `handleStartTimer()`, `handlePauseTimer()`, or `handleResumeTimer()` based on state
   - Shows timer modal when no timer is running
   - Keyboard shortcut registered after all handler functions defined
   - Added visual hint with `<kbd>` element

5. **Entries Page Changes (`app/entries/page.tsx`):**
   - Added `useKeyboardShortcut` import
   - Created `handleQuickEntryShortcut()` function
   - Toggles form visibility
   - Auto-focuses project select with 100ms delay
   - Escape key closes form and calls `handleCancelEdit()`
   - Escape shortcut only active when form is open (disabled: !showForm)
   - Added visual hint with `<kbd>` element in header
