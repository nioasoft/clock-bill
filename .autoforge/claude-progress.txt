### Technical Implementation Notes

**Pause/Resume Flow:**
- Pause: Sets `paused_at = NOW()` in database
- Resume: Calculates `NOW() - paused_at`, adds to `total_paused_time`, clears `paused_at`
- Stop: Subtracts both `total_paused_time` and current pause duration from elapsed time

**Elapsed Time Calculation:**
```typescript
// Base from API (accounts for total_paused_time)
const baseElapsedSeconds = runningTimer.elapsedMinutes * 60 + runningTimer.elapsedSeconds;

if (runningTimer.pausedAt) {
  // Static display - no increment
  displayTime = baseElapsedSeconds;
} else {
  // Smooth ticking - add time since last API poll
  const timeSinceLastUpdate = (now - lastApiUpdate) / 1000;
  displayTime = baseElapsedSeconds + timeSinceLastUpdate;
}
```

**API Polling:**
- Timer state fetched every second from `/api/timer/running`
- API returns accurate elapsed time accounting for all pauses
- Client adds small delta for smooth display between polls
