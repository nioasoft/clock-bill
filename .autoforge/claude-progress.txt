#### 7. Technical Implementation Details

**Why Custom Test Runner?**
- npm registry restrictions prevented installing Vitest/Jest
- Custom runner is lightweight and dependency-free
- Provides essential testing features
- Easy to migrate to formal framework when restrictions are lifted

**TypeScript Compilation:**
- Tests written in TypeScript for type safety
- Can be compiled with: `./node_modules/.bin/tsc -p tsconfig.test.json`
- Or run directly with tsx: `npx tsx tests/unit/format.test.ts`

**Integration Test Design:**
- Requires running dev server
- Can test against local or remote server
- Handles 401 (unauthenticated) responses gracefully
- Validates status codes and response formats
- Supports environment variable configuration (TEST_BASE_URL)

#### 8. Running the Tests

**Unit Tests:**
```bash
npm test              # All unit tests
npm run test:format   # Format tests only
npm run test:validation  # Validation tests only
```

**Integration Tests:**
```bash
# Start dev server first
npm run dev

# Run integration tests (in another terminal)
node tests/integration/api.test.ts

# With custom base URL
TEST_BASE_URL=http://localhost:3000 node tests/integration/api.test.ts
```
