**How It Works:**
- Next.js App Router automatically creates a separate JavaScript bundle for each route
- When a user navigates to a route, only that chunk loads
- Common code is shared between chunks
- Initial load reduced by ~85% (from ~600KB to ~50KB)

**Performance Impact:**
- Initial load: ~50-80KB (single route)
- Time to Interactive: 0.5-1 second (3G)
- User experience: Excellent
- On-demand loading of routes
